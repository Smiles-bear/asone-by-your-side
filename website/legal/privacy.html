二、当前版本处理信息的总体原则

本地优先：聊天记录、助手配置、记忆、日记、用户资料、偏好设置、导入文件等主要保存在您的设备本地。

不经公司服务器中转：当前版本不存在用于接收聊天记录、记忆或 API Key 的公司业务后端。

用户自主选择模型服务：只有当您主动发起模型请求时，App 才会按照您配置的 API 地址将必要请求内容直接发送给对应模型服务提供商。

最小必要：我们不通过当前版本主动收集通讯录、短信、通话记录、精准位置、广告标识符，也未集成广告、行为分析或商业统计 SDK。

四、第三方模型服务与直接传输

Azruiyoi 允许您配置第三方模型服务。当前提供快捷配置入口的服务包括 DeepSeek、Kimi、GLM、Qwen、豆包、MiniMax、混元、文心、星火、Step，并支持自定义 API 地址。具体可用模型、接口能力和服务规则由相应第三方决定。

当您点击发送、检测能力、扫描模型或执行其他需要模型服务的操作时，您的设备可能直接向所选服务商发送：API Key/鉴权信息、模型名称、您主动提交的文本，以及您主动用于该请求的图片、文件内容或其他必要参数（如适用）。该数据传输用于完成您明确发起的功能。我们不通过公司服务器接收、转存或查看这些请求内容。

第三方模型服务提供商会按照其自身的服务协议、隐私政策和安全规则处理其收到的数据。您在使用前应了解并选择适合自己的服务商，并避免向不可信的自定义地址发送 API Key、敏感信息或重要文件。

官方预置地址原则上使用 HTTPS。若您自行填写非 HTTPS、境外或其他自定义地址，传输安全、数据所在地及接收方处理规则可能与官方服务不同，请谨慎选择。

七、保存期限与删除

设备本地数据：通常保存至您主动删除、清除应用数据、卸载应用，或因设备/系统原因被清除。

API Key：保存至您删除对应模型配置、清除应用数据或卸载应用。

客服邮件：以完成咨询、投诉、隐私请求、争议处理以及满足法律要求所必要的最短期限为准。

由于当前版本不将聊天、记忆和 API Key 上传至我们的服务器，我们通常无法从服务器为您找回已在设备端删除、丢失或因卸载而消失的数据。

八、信息安全

API Key 使用系统安全存储机制保存，不以明文写入普通业务数据库。

本地业务数据保存在应用私有存储/数据库中，并受移动操作系统的应用沙箱机制保护。

我们尽量使用安全的网络通信方式；第三方服务、自定义地址、设备系统及网络环境的安全性不由我们单独控制。

请妥善保管您的设备、API Key 和备份文件，不要将 Key 提供给不可信的服务或人员。

九、您的权利与选择

查看和修改：您可以在 App 内查看、修改您自行配置的助手、模型和部分本地资料。

删除：您可以使用 App 内现有删除功能删除相应对话、助手、记忆或配置；也可以通过 Android 系统“清除应用数据”或卸载 App 删除设备上的应用数据。

权限管理：您可以在 Android 系统设置中关闭通知等权限。

停止第三方传输：不再发起模型请求、删除模型配置/API Key，或停止使用相应第三方服务，即可停止后续直接请求。

隐私请求：如您通过客服邮件向我们提供了个人信息，可发送邮件至 851591039@qq.com 请求查询、更正、删除或咨询处理情况。我们将在法律规定或合理必要期限内处理。
