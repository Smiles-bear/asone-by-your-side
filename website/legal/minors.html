本规则由 京山市如一软件科技有限公司 制定，是《Azruiyoi 隐私政策》的专门规则。若使用者不满十四周岁，请由父母或其他监护人（以下简称“监护人”）阅读并同意本规则后，再指导未成年人使用。

一、监护人须知

Azruiyoi 当前为本地 AI 工作台，不设置账号体系，聊天、记忆和配置主要保存在设备本地。使用第三方模型时，请求会由设备直接发送给监护人/用户选择的模型服务商。监护人应了解相应服务商的隐私和使用规则，并决定是否允许未成年人使用。

二、可能涉及的未成年人信息

软件不会主动要求未成年人填写姓名、身份证号、学校、住址等身份信息。但未成年人可能在聊天、助手资料、日记、导入文件或模型请求中自行输入个人信息。因此监护人应指导其遵循最小必要原则，不要提交与功能无关的敏感信息。

设备本地内容：聊天、记忆、日记、助手配置、导入文件等。

第三方模型请求：未成年人主动发送的文本，以及主动用于请求的图片/文件等内容（如适用）。

客服邮件：如监护人主动联系我们，我们可能处理邮箱地址、邮件内容及必要附件。

三、监护人同意与选择

监护人应在充分了解本规则、《Azruiyoi 隐私政策》以及所选第三方模型服务规则后决定是否同意未成年人使用。若不同意，请不要让未成年人继续使用涉及个人信息处理或第三方模型传输的功能。

监护人可通过停止模型请求、删除模型配置/API Key、删除本地内容、清除应用数据或卸载软件等方式停止后续处理。

四、特别保护措施

本地保存优先，不通过公司服务器中转聊天、记忆或 API Key。

API Key 使用系统安全存储机制保存在本地。

不集成广告、行为画像或商业统计 SDK，不以未成年人信息进行定向广告。

如我们发现通过客服渠道收到的不满十四周岁未成年人个人信息缺乏有效监护人同意，将依法采取停止处理、删除等措施。

五、监护人如何行使权利

监护人可帮助未成年人查看、修改或删除设备本地内容；也可通过系统清除应用数据或卸载软件清除本地数据。对于通过客服邮件提供给我们的信息，监护人可联系我们请求查询、更正或删除。

联系邮箱：851591039@qq.com

六、第三方模型服务提示

第三方模型服务商可能根据其自身规则处理收到的请求。监护人应优先选择可信、适合未成年人使用的服务商，并避免使用不明自定义接口。请指导未成年人不要向模型发送身份证号、家庭住址、学校班级、精确位置、医疗健康、金融账户等非必要敏感信息。

七、规则更新

如未成年人个人信息处理方式发生实质变化，我们将更新本规则并依法采取必要的提示、重新取得监护人同意等措施。
