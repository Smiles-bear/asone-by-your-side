# Azruiyoi 隐私政策

版本 V1.1  更新日期 2026年9月6日  生效日期 2026年9月6日

Azruiyoi 是以手机本地处理为主的 AI 工作台。本政策说明我们如何处理你的个人信息，以及你使用第三方模型、语音、远程工具和设备能力时，哪些信息可能由你的设备发送给你选择的服务提供者。

## 一 我们如何处理信息

- **本地优先。** 用户资料、助手资料、聊天、群聊、记忆、日记、世界资料、日历、纸条、互动记录、配置和运行记录主要保存在应用私有目录或本地数据库。
- **用户自主连接。** Azruiyoi 不提供自有大模型或模型额度。模型、远程语音、MCP、HTTP 工具等网络请求由你的设备发送到你选择或配置的地址。
- **按功能使用。** 麦克风、通知、健康数据、使用情况、蓝牙、无障碍、屏幕共享等能力只在相应功能被你开启或使用时调用。拒绝非必要权限不影响无关功能。
- **不用于广告。** 当前版本未集成广告、行为画像或商业统计 SDK，不根据个人信息投放广告。

当前正式版本不通过公司业务服务器中转或保存你的聊天、记忆、API Key、语音或屏幕内容。开发调试环境不属于面向用户交付的正式版本。

## 二 处理的信息和目的

### 1 本地资料与内容

我们在设备本地处理你主动填写或产生的昵称、头像、助手配置、系统设定、聊天和群聊内容、语音及转写、记忆、日记、世界资料、日历、纸条、游戏及一起看、一起听、一起玩记录，用于提供对应功能、恢复历史状态和执行你开启的自动任务。

### 2 模型与语音服务

当你发送消息、检测模型、生成记忆或日记、使用群聊、语音、游戏及互动功能时，设备会按功能需要向所选服务发送 API Key、服务地址、模型名称、提示词、相关上下文、工具结果，以及你主动提交或允许使用的文本、图片、文件、音频或屏幕画面。接收方按照其自己的协议和隐私政策处理这些信息。

### 3 远程工具与网页内容

只有在你添加并启用 MCP 或 HTTP 工具、导入链接或访问远程资源后，设备才会连接相应地址。请求参数可能包含你允许助手使用的对话信息、设备状态或其他数据。请勿连接不可信地址。

### 4 设备能力

你开启相关能力后，应用可能在本地处理麦克风录音、蓝牙设备信息、通知内容、App 使用情况、步数、心率、睡眠、音频播放状态、屏幕画面及无障碍界面信息。部分内容会在你明确发起模型识别、远程语音或远程工具操作时发送给所选服务。

### 5 客服与反馈

你主动发送邮件时，我们会处理邮箱地址、邮件正文和附件，用于答复咨询、处理投诉和排查故障。请先遮挡 API Key、身份证件、金融账户等无关敏感内容。

更完整的逐项说明可在“设置 - 隐私与协议”中的《个人信息处理清单》《权限使用清单》和《第三方服务与组件清单》查看。

## 三 敏感个人信息

健康、行踪轨迹、通信内容以及可能反映身份、生活和设备操作的语音、通知、屏幕画面等，可能属于敏感个人信息。应用会通过功能开关、场景说明和系统授权请求，由你决定是否启用；仅在实现对应功能所必要的范围内处理。涉及依法需要单独同意的场景，我们会在实际启用前另行取得同意。

## 四 保存位置和期限

- 本地数据通常保存至你主动删除、清除应用数据或卸载应用。
- API Key 使用系统安全存储；旧版本迁移数据会在升级过程中转入安全存储。删除对应服务配置、清除应用数据或卸载后停止保存。
- 临时录音、画面和缓存按功能完成情况清理；你明确保存的内容按本地数据规则保留。
- 客服邮件仅在完成咨询、争议处理和履行法定义务所需期限内保存。
- 第三方服务的保存地点和期限由相应服务商规则决定。

## 五 第三方服务和跨境提示

预置入口包括 DeepSeek、Kimi、GLM、Qwen、豆包、MiniMax、混元、文心、星火和 Step，并支持自定义模型、语音、MCP 与 HTTP 地址。你也可以下载由 GitHub 托管的本地语音识别资源。

若你选择境外服务或自定义境外地址，请先了解接收方、数据类型、处理目的、保存地点和权利渠道。停止使用、关闭功能或删除配置可以停止后续请求，但已经发送的数据由接收方按照其规则处理。

## 六 安全措施

应用使用 Android 应用沙箱、本地数据库、系统安全存储、HTTPS 限制和功能授权控制保护数据。任何系统或网络都无法保证绝对安全，请保护好设备、API Key、备份文件和自定义服务地址。

## 七 你的权利

你可以在 App 内查看、更正或删除相应资料、聊天、记忆、日记、配置和记录；在系统设置中关闭权限；在“隐私与协议”中撤回对当前政策的同意。撤回同意会退出应用并停止后续使用，不会自动删除已有本地数据。需要删除全部本地数据时，可先导出必要备份，再使用系统“清除应用数据”或卸载应用。

对于你通过客服提供的信息，可通过 851591039@qq.com 请求查询、更正、删除、限制处理或投诉。我们将在法律规定的期限内处理。

## 八 未成年人

不满十四周岁的未成年人应由父母或其他监护人阅读并同意本政策、《用户协议》和《未成年人个人信息保护规则》后使用。未成年人个人信息属于敏感个人信息，我们将依法给予特别保护。

## 九 政策更新

处理目的、方式、信息种类或对外提供范围发生重大变化时，我们会更新版本并以首次启动提示等显著方式重新征得同意。你不同意更新时，可以停止使用并管理本地数据。
