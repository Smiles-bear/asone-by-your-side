# AsOne（Azruiyoi）社区版

AsOne 是一个以 AI 助手、自然对话和长期陪伴为核心的移动应用。你可以创建属于自己的 AI 朋友、AI 女友、AI 男友、AI 恋人、家人或其他陪伴角色，并按照自己的习惯定义它的性格、表达方式和相处边界。

这个仓库发布的是 **社区版（Community Edition）**：用于了解产品理念、运行公开演示、学习基础契约和参与社区协作。

> 官网：[https://asone.chat/](https://asone.chat/)

## AsOne 能做什么

AsOne 不只是一次问答式的聊天工具，更像是一个可以持续相处的数字伙伴：

- **AI 陪伴关系**：把助手设定成 AI 女友、AI 恋人、朋友、知己、家人或其他你喜欢的角色；关系称呼和相处方式由你自己决定。
- **自然聊天**：围绕日常生活、兴趣、情绪、计划和想法展开连续对话，让交流更接近真实陪伴。
- **多个独立助手**：可以创建多个拥有不同性格和职责的助手，每个助手拥有独立的对话、资料和相处上下文，互不串线。
- **个性化设定**：为每个助手设置沟通风格、行为边界、模型服务和其他偏好，逐步形成适合自己的陪伴方式。
- **长期记忆与连续性**：线上运营版会在授权范围内结合历史对话、记忆和关系状态，让助手能够理解长期相处的背景，而不是每次从零开始。
- **生活协作**：通过日历、小纸条、留言板和其他工具，把聊天延伸到计划记录、提醒和日常整理。
- **共同互动**：线上运营版持续建设一起看、一起听、一起玩、语音和设备协作等能力，让助手参与更多真实场景。

AsOne 的目标不是替用户规定一种关系，而是让每个人都能选择自己舒服的陪伴方式：可以是轻松聊天的 AI 朋友，也可以是更亲密、更有连续性的 AI 女友或 AI 恋人。

## 社区版

社区版是可以独立阅读、构建和运行的公开源码版本，主要用于体验产品的公开基础形态和学习项目架构，包含：

- Flutter 移动端公开界面与基础导航；
- 公开的数据模型和 `OpenCore` 能力契约；
- `DemoCore` 纯内存演示实现；
- 功能页、留言板、小纸条、日历、Token 用量等基础演示；
- 官网静态页面、公开说明和第三方许可证资料。

社区版使用虚构的演示数据，不连接线上运营服务，也不会保存真实账号、真实模型配置或生产数据。因此，社区版展示的是公开 UI、契约和演示数据流，不等同于线上 AI 陪伴服务。应用重启后，演示数据会恢复为初始状态。

社区版适合：

- 了解 AsOne 的公开架构和数据契约；
- 在本地运行一个可复现的 Flutter 演示；
- 基于公开契约开发实验功能或替代实现；
- 通过 Issue、Pull Request 和讨论参与社区协作。

## 线上运营版

线上运营版是 AsOne 面向真实用户提供的正式服务，入口为：

**[https://asone.chat/](https://asone.chat/)**

线上运营版由私有仓库维护、构建和签名，是面向真实用户的完整 AsOne 服务。用户可以在其中配置自己的助手关系，使用 AI 女友、AI 恋人、朋友等不同陪伴方式，并使用真实模型服务、账号体系、数据存储、助手记忆与连续性、主动能力、语音及一起看/听/玩等互动功能。

线上运营版会根据产品迭代持续增加能力，具体功能和开放范围以官网实际提供的版本为准。部分核心实现、服务配置、运营能力和正式发布流程不在本公共仓库中。

线上运营版与社区版属于同一产品体系，但不是同一个可直接互换的构建产物：

- 社区版不会自动连接线上账号或生产服务；
- 从社区版源码构建的安装包不代表官方正式版；
- 线上运营版的功能、服务地址和可用范围以官网实际提供的版本为准。

## 本地运行

```bash
cd frontend
flutter pub get
flutter run
flutter test
```

如果快照不包含平台目录，可先生成干净的 Android 脚手架：

```bash
flutter create --platforms=android --org com.ruyi.community .
```

社区版可以使用调试签名构建本地测试包。正式版必须从私有仓库构建和签名，本仓库不提供正式签名文件。

## 目录说明

- `frontend/`：公开 Flutter 应用子集；
- `frontend/packages/asone_contracts/`：公开数据模型与接口契约；
- `frontend/packages/asone_demo_core/`：契约的纯内存演示实现；
- `website/`：官网静态页面；
- `legal/apk_compliance/`：第三方组件许可证与分发说明。
